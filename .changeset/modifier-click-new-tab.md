ClickableBehavior: Let the browser handle clicks on links with a modifier key pressed (Cmd/Ctrl/Shift/Alt) so that Cmd/Ctrl+click opens the link in a new tab instead of navigating the current page. This affects `Link`, `Button`, `IconButton` and `Clickable` when they have an `href`.
